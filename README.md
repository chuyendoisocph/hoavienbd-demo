# hoavienbd-demo

Website demo **Hoa Viên Nghĩa Trang Bình Dương** — Công ty CP Đầu tư Xây dựng Chánh Phú Hòa (CPHA).

Bản demo được xây dựng bằng Next.js để trình bày giao diện, nội dung dịch vụ và thông tin liên hệ của hoa viên.

## Công nghệ
- Next.js 16 (App Router, React 19, TypeScript)
- Tailwind CSS v4
- Triển khai: Vercel

## Chạy dự án
```bash
npm install
npm run dev
```
Mở http://localhost:3000

## Lệnh
- `npm run dev` — chạy môi trường phát triển
- `npm run build` — build production
- `npm run check` — lint + typecheck + build
